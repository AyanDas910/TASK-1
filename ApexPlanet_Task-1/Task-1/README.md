# GreenLife Garden — Beginner Web Development Project

A responsive, real-world-style landing page for a fictional houseplant shop and care guide.

## Features
- Semantic HTML structure, headings, paragraphs, links, and accessible image descriptions
- CSS styling, responsive layout, typography, spacing, hover states, and reduced-motion support
- JavaScript plant shortlist toast, rotating plant-tip alert, demo email form validation, and dynamic copyright year
- Mobile-friendly design

## Run the project
1. Extract the ZIP.
2. Open the `greenlife_garden_project` folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension in VS Code.
4. Internet access is needed for the remote Unsplash photos and Google Fonts. The rest of the page is local.

## Project structure
- `index.html` — page structure and content
- `style.css` — all visual styles and responsive rules
- `script.js` — interactive behaviour

## Learning objectives
1. Create a webpage with HTML.
2. Style it using CSS.
3. Add JavaScript interactivity.

## Note
This is a front-end demo. The newsletter form does not send or store data, and the plant shortlist is not saved after refreshing. Images are loaded from Unsplash URLs.
